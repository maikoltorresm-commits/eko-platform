## Activar GitHub Pages (solo la primera vez)

1. Abre https://github.com/maikoltorresm-commits/eko-platform/settings/pages
2. Source: **Deploy from a branch**
3. Branch: **main** / carpeta **/ (root)**
4. Save. En 1–2 minutos abre la URL de arriba.
